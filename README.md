# sd2324-proj1

## Technologies and scope

- **Java:** Backend service development.
- **REST and gRPC:** Service APIs for users, videos, and interactions.
- **Distributed systems:** Service discovery and data persistence.


## Overview

Academic distributed systems project based on **Tukano**, a short-video sharing service developed in Java. The repository includes APIs and server components for managing users, videos, and interactions, with REST and gRPC interfaces, service discovery, and persistence support.
